# 🏨 Hospitality Analytics – Power BI

## 📊 Project Overview

This project is an interactive **Power BI report for the Hospitality domain**, created to analyze hotel performance, revenue, and booking data.

The report is divided into three main sections:

- 🏨 **Performance Overview**
- 💰 **Revenue Overview**
- 🛎️ **Booking Overview**

The objective is to transform hospitality data into meaningful visualizations and business insights using Power BI.

---

## 📌 Report Sections

### 🏨 Performance Overview

The Performance Overview focuses on key hospitality performance metrics:

- Revenue
- RevPAR
- ADR
- DSRN
- Occupancy %
- Realisation %
- Revenue by Category
- Trends by Key Metrics
- Property Performance Details

### 💰 Revenue Overview

The Revenue Overview provides analysis of revenue across different dimensions:

- Revenue by City
- Revenue by Property
- Revenue by Room Type
- Revenue by Booking Platform
- Revenue by Day Type
- Monthly Revenue Analysis
- Weekly Revenue Analysis

### 🛎️ Booking Overview

The Booking Overview focuses on booking patterns and performance:

- Weekly Booking Trend
- Total Bookings by Day Type
- Booking Status Distribution
- Top Properties by Total Bookings
- Booking analysis by City
- Booking analysis by Room Type
- Monthly and Weekly Booking Analysis
